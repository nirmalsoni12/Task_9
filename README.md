# CSS Hamburger Menu

# Description
This project is a responsive Laundry Service Web Page built using HTML and CSS. It includes a navigation bar, hamburger menu and a hero section. The hamburger menu is displayed only on mobile view using CSS pseudo-classes.

# Features
- Navigation Bar
- Hamburger Menu
- Mobile Responsive Design
- Hidden Menu by Default
- Menu Opens on Focus
- CSS Pseudo-class
- Laundry Service Hero Section
- Book a Service Button
- Responsive Layout
- Media Queries

# Project Files
- index.html
- style.css
- README.md
- Laundry.png
- Logo.png

# How to Run
1. Download the ZIP file.
2. Extract the ZIP file.
3. Open the extracted project folder.
4. Double-click "index.html" or open it in any web browser.
5. Make sure all project files remain in the same folder.
